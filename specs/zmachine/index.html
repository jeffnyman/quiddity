The Z-Machine Standards Document

Version 1.1 · 24 February 2014

An imaginary computer, created on a coffee table in Pittsburgh in 1979, whose programs are adventure games. This is the complete specification of its architecture, instruction set, text encoding, screen model and file formats.

The latest version of this document can be found at https://www.inform-fiction.org/zmachine/standards/current/
